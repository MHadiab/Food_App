# پروژه درس برنامه‌نویسی پیشرفته: بک‌اند سیستم سفارش آنلاین غذا

این پروژه به عنوان بخشی از نیازمندی‌های درس **برنامه‌نویسی پیشرفته** در دانشگاه توسعه داده شده است. هدف اصلی، پیاده‌سازی یک RESTful API برای یک پلتفرم سفارش آنلاین غذا بوده است که نقش‌های مختلفی مانند خریدار، فروشنده، پیک و ادمین را مدیریت می‌کند.

## 💻 تکنولوژی‌های استفاده شده

- **زبان برنامه‌نویسی:** Java
- **ORM (Object-Relational Mapping):** Hibernate
- **پایگاه داده:** SQLite
- **مستندات API:** OpenAPI 3.0.3

## ✨ ویژگی‌های اصلی سیستم

این API قابلیت‌های جامعی را برای مدیریت یک سیستم سفارش غذا فراهم می‌کند:

- **احراز هویت و مدیریت کاربران (`auth`):**
  - ثبت‌نام، ورود و خروج کاربران با نقش‌های مختلف (خریدار، فروشنده، پیک).
  - مشاهده و ویرایش پروفایل کاربری.

- **مدیریت رستوران و منو (`restaurant`):**
  - ایجاد و ویرایش اطلاعات رستوران توسط فروشندگان.
  - افزودن، ویرایش و حذف آیتم‌های غذایی از منو.
  - مدیریت سفارش‌های ثبت شده برای رستوران.

- **عملیات خریدار (`buyer`):**
  - مشاهده لیست رستوران‌ها و غذاها با قابلیت جستجو.
  - ثبت سفارش، مشاهده تاریخچه سفارشات و ثبت نظر برای غذا.
  - مدیریت رستوران‌های مورد علاقه.

- **عملیات پیک (`courier`):**
  - مشاهده سفارش‌های آماده تحویل.
  - پذیرش و مدیریت وضعیت ارسال سفارش.

- **پنل ادمین (`admin`):**
  - مدیریت کامل کاربران، سفارشات و تراکنش‌ها.
  - ایجاد و مدیریت کدهای تخفیف.

## 🚀 نحوه راه‌اندازی

۱.**کلون کردن پروژه**

۲.**نصب وابستگی‌ها:**
پروژه با استفاده از Maven  قابل ساخت است. وابستگی‌ها (مانند Hibernate و درایور SQLite) به صورت خودکار دانلود خواهند شد.

۳.**اجرای پروژه**:
پس از بیلد موفق، پروژه را اجرا کنید. فایل پایگاه داده SQLite به صورت خودکار در اولین اجرا ایجاد خواهد شد.

##📄مستندات API
جزئیات کامل تمام Endpointها، مدل‌های داده و پاسخ‌های احتمالی در فایل aut_food.yaml موجود در پروژه تعریف شده است.
